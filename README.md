# DigiFont

A **Blazor Web Assembly** web application that lets you directly edit digital fonts such as 7-segment and Dot Matrix fonts in your web browser, and download your customized results as font files.

Users can extract digital fonts in their desired style to a file by adjusting settings such as glyph thickness, spacing, and slant.

## Tech Stack

| Item | Technology |
| --- | --- |
| Framework | .NET 10.0 / Blazor Web Assembly |
| UI Library | MudBlazor |
| Digital Character Rendering Library | [VagabondK.Indicators](https://github.com/Vagabond-K/VagabondK.Indicators) |
| Font File Generation Library | [VagabondK.OpenType](https://github.com/Vagabond-K/VagabondK.OpenType) |
